## 2. 自動テスト項目

`ItemCatalog`・`ItemSearch` の純粋関数を対象とする。フィクスチャはカテゴリとレシピ出力関係の異なるアイテム・レシピ数件で構成でき、同梱マスタには依存しない。

| ID | 内容 | 入力 | 期待 |
|---|---|---|---|
| IC-08 | レシピ出力のあるアイテムのみ抽出 | Outputs に item-a を持つレシピ 1 件と、item-a・item-b・item-c | `WithRecipeOutput` が item-a のみを返す |
| IC-09 | 採取素材でもレシピがなければ除外 | `IsGatherable` で Outputs 未登場の item-g を含む集合 | `WithRecipeOutput` が item-g を返さない（仕様決定 AT） |
| IC-10 | 継続消費系の母集団 | 「気体」「液体」「鉱物」のアイテム | `FuelItems` が気体・液体のアイテムのみを返す（仕様決定 AT） |
| IC-11 | 母集団外の現在値も末尾に残す | 母集団が「気体」のみ、現在値は「鉱物」のアイテム、検索先に全アイテムを渡す | `OptionsForSelection` の `lookupItems` 指定で鉱物アイテムが末尾に残る |
| FIL-05 | カテゴリとクエリの AND 合成 | 「部品」一致かつ「鉱物」カテゴリ指定 | 両条件を満たすアイテムのみを返す |
| FIL-06 | カテゴリのみ指定 | クエリ空・カテゴリ指定 | そのカテゴリのアイテム全件を返す |
| FIL-07 | カテゴリ未指定は従来どおり | category に null | クエリ絞り込みのみで動く（回帰） |

FIL-05〜07 は `ItemSearch` の呼び出し元が Phase 20 で消滅し、`ItemSearchTests` が Phase 22-2（仕様決定 BB〜BE）で削除されたため廃止項目である。
[test-specification-phase4.md](test-specification-phase4.md) §FIL の FIL-05（選択解除判定）は同番号の別対象で、`ItemDeselectTests` として現存する。

razor の UI 状態遷移（カテゴリ select の切替、行ごとの独立状態、ListPane の合成絞り込み）は bUnit 未導入のため対象外とする（remaining-issues.md「Razor ページ内 UI 状態遷移のテスト空白」）。
`dotnet test` は回帰確認として全件実行し、全緑であることを受け入れ条件とする。

## 3. 手動確認項目（ブラウザプレビュー）

実装のブラウザプレビューをユーザーに操作してもらい、次を確認する。
Admin ホームでマスタを読み込み、ナビの各ページと公開 App で確認する。

| ID | 確認内容 |
|---|---|
| MN-53 | 公開 App 生産リストで行のカテゴリを選ぶと検索候補がそのカテゴリに絞られ、テキスト検索と併用できる。候補はレシピ出力のあるアイテムのみで、レシピ出力のない採取素材（鉱物・水・ガス等）は出ない |
| MN-54 | Admin 計算プレビューの生産リストがカテゴリ＋アイテムの横並びになり、候補はレシピ出力のあるアイテムのみ |
| MN-55 | レシピ編集の入力・出力・固定消費の各行がカテゴリ＋アイテムの横並びになり、行ごとに独立して絞り込める。固定消費の候補は気体・液体のみ |
| MN-56 | 環境編集の消費アイテムがカテゴリ＋アイテムの横並びになり、候補は気体・液体のみ |
| MN-57 | マップ編集の採取レート行がカテゴリ＋アイテムの横並びになり、候補は天然資源のみ |
| MN-58 | アイテム一覧の検索窓にカテゴリ select が追加され、テキスト絞り込みと併用できる |
| MN-59 | 絞り込み中に、条件外のアイテムを選んでいた行が末尾に現在値を残し、別アイテム表示に化けない（Phase 14 の MN-34 の横展開） |
| MN-60 | 生産リスト（公開 App・Admin 計算プレビュー）で先の行を削除しても、残った行のカテゴリ絞り込みが削除した行のものに化けない（Devin Review 指摘の回帰） |
| MN-61 | アイテム一覧で絞り込み中のカテゴリに属する最後のアイテムを削除または別カテゴリへ変更したとき、絞り込みが「すべてのカテゴリ」に戻り、一覧が空のままにならない（Devin Review 指摘の回帰） |
