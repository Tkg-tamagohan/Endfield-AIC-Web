共通: 全レシピ `VersionAdded = "1.0.0"`、イベントなし、採取素材 `i-ore` は無制限。

Id の辞書順は「`r-q1-lean` < `r-q1-rich`」「`r-q2-a-slow` < `r-q2-b-fast`」「`r-q4-alt` < `r-q4-multi`」「`r-q8-a-thin` < `r-q8-b-rich`」など、レート優先と Id 昇順が逆方向に効く命名にし、第二キーの効果を分離して検える形にする。
環境 `env-q5`・`env-q6` は `GameEventId = "ev-off"`（計算コンテキストでは無効）とする。

なお既存フィクスチャ F-04 派生 `F04WithByproduct` の `r-x` は、新規則では i-a 副産物の実効レート（15/分）が循環レシピ `r-cyc-a`（10/分）を上回り、i-a の既定が r-x に移って BYP-07 の検証趣旨（循環未充足への副産物到着）が失われる。
そのため `r-x` の CycleTime を 4秒→8秒に変更し、実効レート 7.5/分として従来の選択を維持する（副産物の供給量は i-x 需要連動のため不変）。
