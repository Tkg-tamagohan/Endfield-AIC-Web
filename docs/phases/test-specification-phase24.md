**前提ドキュメント**: [implementation-plan-phase24.md](implementation-plan-phase24.md)、[decision-records.md](../decision-records.md)（仕様決定 BJ〜BL）

> 本書は Phase 24 の検査項目を ID 付きで管理する。実施結果は PR 本文に表で記録する。

## 1. モデル検査

`FlowGraphModelBuilder` と Domain は本 Phase で変更しないため、新規の xUnit ケースは原則追加しない。
`dotnet test` 全緑による既存 FG 群の回帰確認をもってモデル側の検査とする。

## 2. 手動確認項目

E2E 検証は WebGPU 対応 Chrome で行う。
ピンチは CDP の `Input.dispatchTouchEvent` で 2 点タッチを合成して検証し、スマホ幅の確認は同じく CDP の表示幅エミュレーションを使う。
縦レイアウトのノード間隔と粒子定数（`PARTICLE_COUNT_MIN`・`PARTICLE_COUNT_MAX`・`PARTICLE_SATURATE_PER_MINUTE`）の調整値は本仕様では未定である。実装時の暫定値をユーザーへ確認してから、以下の確認項目を実施する。

| ID | 対象 | 条件 | 期待 |
|---|---|---|---|
| MN-83 | 既定の表示方向 | 計算結果でグラフを開く | 既定が縦で、原料が下・目標アイテムが最上行に並ぶ。エッジはソース上辺中央からターゲット下辺中央へ接続する |
| MN-84 | 横への切替 | ツールバーで「横」を選択 | 従来の左から右表示へ切り替わり、再フィットされる。縦へ戻すと再び縦配置になる |
| MN-85 | 縦表示の後退エッジ | 種↔作物循環を含む計画を縦で表示 | 循環の後退エッジが側面に膨らむループとして見える |
| MN-86 | 高さハンドル | 下端ハンドルを上下へドラッグ | 高さが追従して変わり、ドラッグ中ビューの拡大率と位置は維持される。既定値（420px、モバイル幅 300px）より小さくならない |
| MN-87 | 最大化と復帰 | 最大化ボタン押下後、ボタン再押下または Esc | 画面全面のオーバレイへ展開し、復帰できる。展開中もパン・ズーム・高さ調整が有効で、ページ本体はスクロールしない |
| MN-88 | ピンチズーム | 領域内で 2 点タッチを開閉（CDP 合成） | 中点をアンカーに拡大縮小し、中点の移動でパンも動く。倍率は 0.2〜1.5 の範囲に制限される |
| MN-89 | ノード上発のタッチ操作 | ノード上で 1 点ドラッグと 2 点ピンチ | ページのスクロール・ページズームを起こさず、ドラッグはパン、ピンチはズームとしてグラフが応答する。しきい値未満のタップは従来どおりリストジャンプになる |
| MN-90 | ズームボタン | ＋・−・フィットを押す | ＋・−は領域中心アンカーで段階的に拡大縮小、フィットはグラフ全体を領域内に収める |
| MN-91 | 台数分表示との併用 | 縦表示で「設備を台数分表示」を有効化 | ユニットノードが行内に並び、容量超過判定の赤化が集約表示と整合する（AN の不変条件） |
| MN-92 | グラフ⇄リストの往復 | 横へ切替えてから「リスト」→「グラフ」と戻す | 再表示時も直前の方向・高さを維持する（状態は `CalculatorPanel` が保持）。ページを離れて戻ったときは既定の縦に戻る |
| MN-93 | ヒント文言 | グラフ表示時のヒント | ピンチを含む表現へ更新されている |
| MN-94 | Admin 側の同一動作 | 管理ツール計算プレビューでグラフを開く | 公開 App と同じ切替・ハンドル・最大化・ズーム操作が使える |
| MN-95 | 非対応環境のフォールバック | WebGPU 非対応のブラウザ幅で開く | 従来どおりグラフ領域と切替を出さずリスト表示のみになる（AK の不変条件） |
