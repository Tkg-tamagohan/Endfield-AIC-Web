## 1. フィクスチャ（F-17 系）

正味増循環の検査に使う新規フィクスチャ。ID は CalculationFixtures の F-xx 系列に続けて採る。

| フィクスチャ | 構成 | ループゲイン |
|---|---|---|
| F-17（芽針型） | r-grow: i-seed×1 + i-water×1 → i-crop×2（f-grow）。r-pick: i-crop×1 → i-seed×1（f-pick）。i-water は採取無限 | (1/2)×(1/1) = 0.5 |
| F-17 種側型 | r-grow2: i-seed×1 → i-crop×1。r-pick2: i-crop×1 → i-seed×2 | (1/1)×(1/2) = 0.5 |
| F-17 正味減型 | r-na: i-b×2 → i-a×1。r-nb: i-a×1 → i-b×1 | (2/1)×(1/1) = 2 |
| F-17 下流型 | F-17 に i-char と r-char（i-crop×1 → i-char×2）を追加 | 0.5（同上） |
| F-17 採取型 | i-ore 採取可（上限 60）。r-ore: i-x×1 → i-ore×2。r-x: i-ore×1 → i-x×1 | (1/2)×(1/1) = 0.5 |
| F-17 固定消費型 | F-17 の r-grow ペアに i-water 固定消費 6/分を追加 | 0.5（同上） |
| F-17 混合型 | r-a: i-b×1 + i-c×1 → i-a×1。r-b: i-a×1 → i-b×2。r-c: i-a×2 → i-c×1 | A→B→A = 0.5、A→C→A = 2 |
| F-17 混合副産物型 | F-17 混合型に i-x・i-ore・r-px（i-ore×1 → i-x×1 + i-c×1）を追加 | A→B→A = 0.5、A→C→A = 2 |

### 設計上の保険（別採番なし）

解放ステップは「循環由来の残差合計が縮まない場合に打ち切る」終了条件を持つ。
複雑に絡み合った循環で反復が発散しないための保険で、ゲイン判定が解放を許したケースでも残差が縮まなければ解放を止めて従来の未充足＋警告へ戻る。
同一アイテムへ正味増・正味減の複数循環が絡むケースは、ライブな枝の検出だけが拒否権を持つ判定で防ぐ（NCP-09）。副産物で枝が死んだ検出は拒否権を失い、残る正味増経路だけで収束する（NCP-10）。
