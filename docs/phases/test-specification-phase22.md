## 1. テスト環境と実行方法

| 項目 | 内容 |
|---|---|
| 自動テスト基盤 | xUnit（`tests/EndfieldAicWeb.Application.Tests` ほか既存プロジェクト） |
| 実行コマンド | `dotnet test`、および `~/.venvs/validate/bin/python tools/validate_master.py`（マスタ未変更でも回帰確認として実行） |

| 手動確認 | App・Admin を `dotnet run` で起動し、ブラウザプレビューで §3 の項目を確認する（ui-mock-first ルールに従い、ユーザー確認を先に取る） |

## 2. 自動テスト項目

本 Phase は挙動不変の移設と表示の統一が主であり、新規の純粋ロジックは原則として発生しない。
共有化の過程で新たな関数・変換が Application 層へ抽出された場合に限り、本節へ ID を採番して追加する。

| ID | 内容 | 入力 | 期待 |
|---|---|---|---|
| — | （新規ロジックが発生した場合のみ追加） | — | — |

`ItemSearch`（Application）の削除に伴い `ItemSearchTests` も削除する。Phase 20 で呼び出し元がなくなっており、残置はデッドコードとそのテストの維持になるため。
それ以外の既存テストは変更しない前提とし、失敗が出た場合は原因を切り分けて報告する。
razor の UI 状態遷移（コンポーネントの描画・イベント）は bUnit 未導入のため対象外とする（remaining-issues.md「Razor ページ内 UI 状態遷移のテスト空白」）。
`dotnet test` は回帰確認として全件実行し、全緑であることを受け入れ条件とする。

## 3. 手動確認項目（ブラウザプレビュー）

実装のブラウザプレビューをユーザーに操作してもらい、次を確認する。
Admin ホームでマスタを読み込み、ナビの各ページと公開 App で確認する。
MN-72〜75 は PR 22-1（挙動不変の移設）、MN-76〜79 は PR 22-2（差異の統一と Admin グラフ解放）、MN-80 は回帰確認の項目である。

| ID | 確認内容 |
|---|---|
| MN-72 | 公開 App の計算ページが共有コンポーネントへ移設後も従来どおり動作する。目標行のカテゴリ・アイテム select による絞り込み、レート入力、計算ボタン、結果の素材・採取・環境・設備・消費電力・余剰の各節、単位切替・期間入力・有効イベント・採取マップの入力保持が変わらない（22-1） |
| MN-73 | 公開 App で生産フローグラフが従来どおり表示・操作できる。台数分表示・集約表示の切替、グラフノードからリスト行へのスクロール（`data-flow-ref`）が動く（22-1） |
| MN-74 | Admin 計算プレビューが移設後も従来どおり動作する。ホームで読み込んだ編集中データで計算され（`EnsureSnapshot`）、検証エラーがあるとゲートが出て、フッターにデータ版と出典ラベルが表示され、アイコンが編集中データ由来で解決される（22-1） |
| MN-75 | Admin 編集系ページ（Items 等のアイコン表示箇所）が共有 `EntityIcon` へ追従後も従来どおり表示される（22-1） |
| MN-76 | Admin 計算プレビューで生産フローグラフが表示・操作できる。台数分表示・集約表示の切替と `data-flow-ref` スクロールが動く（仕様決定 BC、22-2） |
| MN-77 | 採取マップ節ヒント等の表示文言が公開 App・Admin ともに「天然資源」に統一される。マスタ JSON の Category 由来の表示（カテゴリ選択肢等）は「採取素材」のまま変わらない（仕様決定 BD、22-2） |
| MN-78 | 目標アイテムの選択肢名に、イベント由来アイテムの「（イベント）」注記が両アプリで付く（22-2） |
| MN-79 | Admin で計算実行が例外となるデータ状況（検証を通るが計算に失敗する編集データ等）で、アプリが落ちず入力エラー欄へメッセージが表示される（仕様決定 BE、22-2） |
| MN-80 | スマートフォン幅（320px 程度）でも両アプリの計算ページが折り返して表示され、共有化によるレイアウト崩れがない（仕様決定 K の回帰） |

## 4. 受け入れ条件との対応

- 両計算ページが同一の共有コンポーネントで描かれること: §3 の MN-72〜76 で担保（両アプリが同じ機能を同じ見た目で提供する）
- Admin でグラフが表示・操作できること: MN-76 で担保
- 主要フローの動作（デスクトップ・スマホ幅）: MN-72〜74・MN-80 で担保
- `dotnet test` 全緑・`validate_master.py` 通過・CI 緑: §2 の回帰確認で担保
