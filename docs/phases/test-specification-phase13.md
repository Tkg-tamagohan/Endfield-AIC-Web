## 1. テスト環境と実行方法

| 項目 | 内容 |
|---|---|
| 自動テスト基盤 | xUnit（既存プロジェクト。本 Phase は自動テストの追加なし） |
| 実行コマンド | `dotnet test`、および `~/.venvs/validate/bin/python tools/validate_master.py` |
| 実行環境 | Linux。CI（ubuntu-latest）でも実行される |
| 手動確認 | Admin を `dotnet run` で起動し、ブラウザプレビューで §4 の項目を確認する（ui-mock-first ルールに従い、ユーザー確認を先に取る） |

## 2. 自動テストの扱い

本 Phase は公開版から Admin への UI コピー追従であり、Application・Domain 層の新規ロジックを含まない。
移植先で使う判定・パース・候補絞り込みは次の既存テストで担保済みであり、再実装のテスト化は行わない。

- ペア代替選択: `PairOptionTests`、計算への適用は Domain 側の既存ケース
- 散布機台数入力: `CalculationInputBuilderTests`（`TryParseEnvironmentCounts`）
- 単位切替・期間換算: `PeriodAmountTests`、`ResultViewTests` など
- マップ候補・既定上限・採取レート入力: `MapSelectionTests`、`CalculationInputBuilderTests`（`TryParseGatherRates`）、Domain の GAT 系

razor の UI 状態遷移は bUnit 未導入のため対象外（remaining-issues.md「Razor ページ内 UI 状態遷移のテスト空白」）。
`dotnet test` は回帰確認として全件実行し、全緑であることを受け入れ条件とする。

## 3. フィクスチャ

手動確認には実装計画 §5 のプレビュー用マスタを使う。
同梱マスタに、イベント所属マップ `map-event`（`ev-first` 所属、原鉱石 無限）と、採取素材を産出するレシピ `recipe-ore`（固形燃料 1 → 原鉱石 1、加工機 4 秒）を加えたものを、稼働中 dev server の `src/EndfieldAicWeb.Admin/wwwroot/data/master.json` に配置する。

## 4. 手動確認項目（ブラウザプレビュー）

実装のブラウザプレビューをユーザーに操作してもらい、次を確認する。
Admin ホームで「同梱マスタを読み込む」（§3 の差し替え済みマスタ）→ ナビの「計算プレビュー」で確認する。

| ID | 確認内容 |
|---|---|
| MN-20 | アイテム選択が `RefSelect` のままで、計算結果が出る。素材・設備・消費電力・余剰の各節が表示される |
| MN-21 | 汎用部品 10/分の計算で、素材行にペア選択ドロップダウンが出る。別ペア（加工機 4 秒・環境なし）を選ぶと即時再計算され、環境節と散布機入力行が消え、供給チップと設備が切り替わる |
| MN-22 | 環境節の散布機台数を自動値（1）から 0 へ変えると消費量に反映される。範囲外や非整数の入力はエラー表示で再計算されない |
| MN-23 | 単位切替で毎秒・期間に変わる。期間選択時は日・時・分の入力欄が出て、素材・チップ・余剰が期間換算される。期間が非数値ではエラーが出る。消費電力は換算されない |
| MN-24 | 採取マップの選択肢に「未選択（採取無制限）」とマップ名が出る。`map-event` は `ev-first` を有効にしたときだけ候補に出る |
| MN-25 | サンプル採取地を選ぶと即時再計算され、採取節に原鉱石・固形燃料・活性ガスの行が出る。既定上限（240、無制限、0）が読める |
| MN-26 | 原鉱石の利用可能レートを既定より小さく入力して確定すると、超えた分が `recipe-ore` で生産され「上限到達」が付く。空欄に戻すと既定値へ戻る |
| MN-27 | 利用可能レートに非数値や負の値を入れるとエラーが出て、計算結果は前回のまま残る |
| MN-28 | 目標数量・ペア選択・マップ変更で再計算しても、採取レートと散布機台数の入力値が保持される |
| MN-29 | `map-event` を選んだあと `ev-first` のチェックを外すと、選択が「（イベント無効）」表記で残り、`GatherMapUnavailable` の警告が出て採取節が消える |
| MN-30 | 供給内訳のチップが「採取 X」と表示される。毎秒表示に切り替えても採取節と環境行は個/分のまま |
| MN-31 | スマートフォン幅（780px 未満）で 1 カラム化し、マップ選択・採取節・期間入力が潰れない |
